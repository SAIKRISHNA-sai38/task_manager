# Task Manager

A simple task management web application built using Flask, HTML, CSS, and SQLite.

## Features

- Add tasks
- View tasks
- Update tasks
- Delete tasks
- Simple and user-friendly interface
- SQLite database integration

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
